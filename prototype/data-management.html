Data retention policy

Requires management approval No booking record is removed automatically. A retention period only makes older records eligible for archiving; an administrator must review and confirm each cleanup run.

AIKOL confirmed 7 years for audit purposes, with expired records exported rather than archived in place or silently deleted. Cleanup runs in batches of 1,000 records inside a transaction, and every run is written to the audit log with the number of records exported or deleted. A database backup is taken first and copied to external storage.

Restricted operations

A full database reset removes every booking, venue and user record. It exists for development, testing and migration work and is not intended for normal production use.

  • Available only to the highest administrator level.
  • A confirmation phrase must be typed in full.
  • A backup is created before the operation proceeds.
  • The action is written to the audit log.
