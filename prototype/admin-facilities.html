How the code and the name differ

Each facility has a code and a name. The code is the stable identity: CSV imports and saved filter links refer to it, and it never changes once created. The name is the label people see, and may be edited freely.

If the display name were also the key, correcting a spelling mistake would break every import template and saved link that referred to it.
